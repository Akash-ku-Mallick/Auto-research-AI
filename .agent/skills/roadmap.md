# Roadmap

Phase 1

- Setup Vite + Redux Toolkit (RTK) + RTK Query boilerplate
- Setup lightweight Express + TypeScript backend with Repository Pattern
- Implement config UI to configure database credentials and save them in `system_configs`
- Implement dynamic database connection bootstrap (Mongoose / Prisma)
- RSS feeds, HN, and GitHub Trending scraper implementations

Phase 2

- AI Provider layer integration (Gemini + Ollama Llama 3.3)
- Article analysis prompts and relevance scoring engines
- Local Ollama first-stage filtering to save API costs
- Markdown reports generation
- Telegram notifications delivery

Phase 3

- Interactive Research Dashboard (React + RTK)
- Trend Clustering algorithm and clustering UI
- User management and saved searches

Phase 4

- Notion sync
- Slack integration
- Multi-user support

Phase 5

- Content planning calendar generation
- Predictive trend forecasting
