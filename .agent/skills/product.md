# Product Overview

Project Name: ResearchPulse

## Mission

ResearchPulse automatically discovers, analyzes, scores, and summarizes high-signal technology trends from multiple sources.

The goal is to eliminate manual research and provide actionable content opportunities for developers, founders, creators, and technology professionals.

## Core Workflow

Sources → Filtering → AI Analysis → Scoring → Trend Clustering → Research Dashboard

## Target Users

* Developers
* Startup Founders
* Technical Content Creators
* Product Managers
* AI Enthusiasts

## Primary Features

* Automated source ingestion
* Topic whitelisting
* Topic blacklisting
* AI-based relevance scoring
* Trend detection
* Content hook generation
* Markdown report generation
* Telegram delivery
* Notion delivery
* Dashboard analytics

## Non Goals

* Social media scheduling
* Content publishing
* SEO management
* CRM functionality
