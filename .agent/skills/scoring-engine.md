# Research Scoring System

Every article receives scores from 1 to 10.

## Categories

### Developer Impact

Does this affect:

* Frontend developers
* Backend developers
* AI engineers
* Startup builders

### India Relevance

Does this affect:

* Indian startups
* UPI
* AI regulations
* Indian developer ecosystem

### Novelty

How new is the information?

### Viral Potential

Likelihood of becoming widely discussed.

### Visual Potential

Can it be explained visually within 60 seconds?

## Final Score

Formula:

finalScore =
(
developerImpact * 0.35 +
indiaRelevance * 0.20 +
novelty * 0.20 +
viralPotential * 0.15 +
visualPotential * 0.10
)

Range:
1–10

## Thresholds

8–10 = High Priority

6–7 = Medium Priority

0–5 = Ignore
